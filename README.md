# ACN 工具集

Windows 小工具合集，由一个启动器统一管理。作者：B 站 **@小南娘可可**。

## 怎么用

只需要下载**一个文件**：

### ⬇️ [ACNBoot.exe](https://github.com/xnnkk/ACN-Tools/releases/latest/download/ACNBoot.exe)

334 KB 的零依赖原生程序，**没装 .NET 也能跑**。双击它之后：

1. 自动检查 .NET 8 桌面运行时 —— 没有就问你一句，点「是」自动装好
2. 自动从本仓库下载启动器并打开
3. 在启动器里点右上角 **设置**，选你想要的模块点 **下载**
4. 回主界面点 **启动**

## 包含的模块

| 模块 | 说明 |
|---|---|
| 音乐播放器 | ape / flac / wav 等全格式，带格式转换、均衡器、虚拟环绕 |
| 按键显示 | 屏幕上实时显示 W / A / S / D / 空格 / 鼠标左右键，附左右键 CPS |
| 连点器 | 长按开松关，自定义热键与点击键，可配置多组 |
| 按键录制 | 录制鼠标键盘全部操作并回放，可调播放速度、可循环 |

## 说明

- 模块以 `<模块Id>-<版本>.zip` 的形式放在 [Releases](../../releases) 里，启动器会自动下载，**正常使用不用手动下**。
- 软件安装位置：`%LOCALAPPDATA%\ACNLauncher`
- 所有模块共用同一套界面风格（深色底板 + 圆角 + 黑白灰）。
